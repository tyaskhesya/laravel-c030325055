# Praktikum Laravel

## Deskripsi
Proyek ini merupakan proyek praktikum mata kuliah Pemrograman Web menggunakan framework Laravel.

## Teknologi
- Laravel
- PHP
- MySQL

## Cara Menjalankan

1. Install dependency:
   composer install

2. Jalankan migration dan seeder:
   php artisan migrate:fresh --seed

3. Jalankan server Laravel:
   php artisan serve
